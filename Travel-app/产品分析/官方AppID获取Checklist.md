# 官方小程序 AppID 获取 Checklist（手机微信版）

> 状态：✅ **2026-08-10 已完成**。13 个 AppID 已从截图提取并填入 `data/spots.json`（已同步 mock / 云函数副本）；4 个景点**确认没有小程序**（仅公众号/官网/票务网页），`officialAppid` 保持为空，走公众号 + 官网兜底。
> 来源：微信生态不公开索引 appid，桌面版自动化会被风控（已实测触发「重新登录」），故采用**手机微信人工查看**。全程不碰账号安全。

## 操作步骤（每个景点重复一次）

1. 手机打开微信 → 顶部搜索框，输入下表中的「小程序搜索名」→ 点搜索结果里的**小程序**（不是公众号/文章）
2. 进入小程序后，点**右上角「···」**（更多）
3. 在弹出的菜单里点**「更多资料」**（部分版本叫「查看资料 / 关于」）
4. 在资料页找到 **AppID**（形如 `wx8f815c1df1f067ef`），抄下来
5. 填到下表对应行，完成后把整张表发给我即可

> ⚠️ 如果「更多资料」里**看不到 AppID**（有的只显示名称/主体），在该行备注「看不到」，我另想办法。
