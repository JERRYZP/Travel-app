## 一、集合与权限（云开发控制台 → 数据库 → 新建集合）

本项目**小程序端不直连数据库**（全仓无 `wx.cloud.database()`，数据全走 `wx.cloud.callFunction`），而云函数用管理端凭据读写、**不受集合权限限制**。因此 17 个集合一律选 **「仅管理端可读写」**：功能完全不受影响，同时把所有小程序端直连入口关死，最安全。

| 集合 | 用途 | 权限 |
| --- | --- | --- |
| `spots` | 26 个景点主数据 | 仅管理端可读写 |
| `release_rules` | 放票规则（原 `rules`，**不要再建 `rules`**） | 仅管理端可读写 |
| `users` | 用户资料 + 订阅消息额度台账（按 `openId`） | 仅管理端可读写 |
| `trips` | 行程（按 `userId`） | 仅管理端可读写 |
| `trip_items` | 行程项：景点 + 出行日 + 人工结果 + 提醒开关（TABLE-008） | 仅管理端可读写 |
| `reminder_tasks` | 提醒任务 | 仅管理端可读写 |
| `reminder_cart` | 提醒清单 | 仅管理端可读写 |
| `search_history` | 搜索历史 | 仅管理端可读写 |
| `feedbacks` | 意见反馈 + 信息纠错（TABLE-008） | 仅管理端可读写 |

- 权限四档（控制台原文，从宽到紧）：仅创建者可写，所有人可读 / 仅创建者可读写 / 仅管理端可写，所有人可读 / **仅管理端可读写**。
- 已废弃集合：`favorites`（收藏功能已下线，不要建）。
- ⚠️ **云存储权限不要跟着设成「仅管理端可读写」**：头像是小程序端 `wx.cloud.uploadFile` 直传的（`profile-edit.js` → `avatars/{ts}_{rand}.{ext}`），必须保留客户端写权限，用默认的「所有用户可读，仅创建者可读写」。

| `reminder_daily_stats` | `dateKey` + `metricType` + `spotId` | 每日汇总 upsert 与区间统计 |
| `reminder_daily_stats` | `dateKey` | 永久汇总区间查询 |
| `admin_audit_logs` | `createdAt` | 审计列表与按时间排查 |
| `admin_audit_logs` | `expireAt` | 180 天分批清理 |

> `reminder_events.eventKey` 是逻辑幂等键；云开发控制台不承担唯一约束，查重与去重由 `admin.rollupDaily` 完成。

> 客服工作台 `adminReminderQuality.stats` 同时按 `releaseAt` 范围查询并 `orderBy('releaseAt','asc')`，依赖 `reminder_events.releaseAt` 与 `reminder_tasks.releaseAt` 两条单字段索引。部署含该接口的 `payment` 前必须先在控制台核验；缺任一索引时不得只看本地测试通过就部署。

## 说明

- 云开发数据库索引为「等值 + 排序」复合索引：字段顺序要严格按上面列出，**排序字段必须跟在等值字段之后**。`search_history` / `feedbacks` 原先只列了单字段 `userId`，而实际查询带 `orderBy`，单字段索引带不动排序，故已补全为 `userId` + 排序字段。
- 全部用升序即可：`orderBy('releaseAt','asc')` 由升序索引直接覆盖；`orderBy('searchedAt','desc')` / `orderBy('createdAt','desc')` 可由升序索引反向扫描，**不需要**另建降序索引。
- 「唯一」一律**不勾选**——云开发控制台索引不承担业务唯一性。`trip_items` 的 `(userId, tripId, spotId, visitDate)` 为逻辑唯一约束，由云函数查重保证；`reminder_cart` 同理需把 `tripId` 纳入逻辑唯一键。
- 单字段索引也要单独建，复合索引不替代它（例如 `reminder_tasks` 同时需要 `userId` 单字段与 `userId + tripId` 复合，二者用途不同，都要建）。
- 建完索引后，集合总量仍很小时（几百条内）不必急着建全部「建议」项；但第二节「必须」项，特别是 `reminder_tasks` 通知扫描索引和 `trip_items` 首页读取索引，必须先建。
