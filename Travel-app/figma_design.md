# 景点预约提醒 · Figma 视觉规范

> 来源：`src/imports/DesignTokens-1` 与 PAGE-01 / 02 / 03 / 04 / 05 / 07 的 Figma Make 导入。本文是微信原生小程序实现的统一视觉基线；导入文件保持只读。

## 1. 视觉定位

**京味预约手册**：以宣纸暖白为基底、朱砂红作为唯一高亮，辅以低饱和金棕描边与北京地标摄影。界面保持轻量、安静、带一点传统书卷感；不使用冷蓝或高对比渐变。

## 2. 色彩

| Token | 值 | 使用 |
|---|---:|---|
| `--color-page` | `#F8F3EA` | 页面底色 |
| `--color-surface` | `#FFFEFB` | 卡片、输入框、底部栏 |
| `--color-primary` | `#C0472A` | 主按钮、选中态、提醒强调 |
| `--color-primary-soft` | `#EAA091` | 已选按钮 |
| `--color-ink` | `#4A2D23` | 标题与主要文字 |
| `--color-text` | `#7A5540` | 次级正文 |
| `--color-muted` | `#B8904A` | 图标、引导文案 |
| `--color-placeholder` | `#DBCDBB` | 占位文字 |
| `--color-border` | `#EDE0C8` | 细描边 |
| `--color-cream` | `#EDE5D2` | 主按钮图标 |

难度标签：极难约 `#F5DDD5 / #C0472A`；较难约 `#F2E4C0 / #C26B0C`；容易约 `#D8EAD8 / #4A7C59`。

## 3. 字体

- 标题、按钮、标签：`寒蝉端黑宋 Medium`；正文与辅助信息：`寒蝉端黑宋 Regular`。
- 微信端通过 `wx.loadFontFace` 加载 CDN 字体；加载失败或未配置 CDN 时降级为 `PingFang SC, sans-serif`。
- 页面标题 15px；段落标题 15px；景点名 14px；按钮 13px；标签/辅助 10–12px。

## 4. 尺寸、间距与层次

- 设计基准宽度 402px，页面左右内边距 16px；主内容宽 370px。
- 模块间距 16px，卡片内部间距 8px，标签间距 4px。
- 输入/主按钮高度 44px；小选择按钮高 24px；景点图片高 68px。
- 常规圆角 12px；图片/小按钮 6px；标签 4px；城市胶囊 26px。
- 阴影：卡片 `0 1px 4px rgba(100,60,20,.08)`；输入框 `0 1px 8px rgba(100,60,20,.08)`；底部导航 `0 2px 6px rgba(100,60,20,.10)`。

## 5. 组件规则

### 输入框
暖白底 + `#EDE0C8` 1px 描边 + 金棕线性图标。日期输入显示“开始日期 — 结束日期”；景点输入为空时显示“北京必游：故宫博物院、国博”。

### 景点卡
两列等宽网格。白底、12px 圆角，8px 内边距；首部为 68px 高地标图。景点名称使用朱砂红下划线；难度为低饱和色块；预约规则以金棕小标签显示。右上角为“+ 选择”或“✓ 已选”的状态按钮。

### 主行动
44px 高朱砂红圆角按钮，白色文案与星光图标；用于推动用户生成时间线（`pages/add-trip`）与提交清单（表单页）。

### 行程状态标签（2026-09-20 新增）
六个展示态各自「浅底 + 深字」的对称色，底色走低饱和暖调、与难度标签同一族：
`待抢` 朱砂底（还没到点，最需要盯着）/ `可抢` 金底（该动手了）/ `已成` 绿底 / `未成` 朱砂底 /
`待确认` 米底（中性态，不判失败）/ `免预约` 米底。
⚠️ **历史区的「没抢到」不用红色**——红色是行动召唤色，历史里的失败已经无法挽回，
用行动色只会让用户以为还能做点什么。token 定义在 `app.wxss` 的 `--state-*`。

### 底部导航
暖白底、**三项等宽（提醒／景点／我的）**，选中项为朱砂红；未选中项为 `#B09878`。在 V1 以页面内自绘导航实现（`components/tabbar`），后续多页面完成时可迁移到 custom-tab-bar。

> ⚠️ **2026-09-20 订正**：本节原文写「两项等宽（提醒／我的）+ 数字角标」，与实现不符——实际是三项，且**角标已于 2026-08-20 废弃**（`REMINDER-RULE-007`，含 `task.badge` 接口），`UI-007` 也已是「无角标」。以本节现文为准。

## 6. 页面 PAGE-01 创建态

顶栏居中“景点预约提醒”，左侧“游北京”城市胶囊。表单位于顶部，先问“在北京玩几天？”再问“选择哪些地方玩？”，随后提供“生成预约时间线”。热门景点区以两列卡展示当前预约状态，下方有轮播指示、更多景点按钮与“为你生成专属抢票时间线”提示。内容在底部导航上方滚动。

> **2026-09-20**：本页（表单 + 时间线）已从首页剥离为独立页 `pages/add-trip`，首页改为**行程状态墙**（吸顶横幅 + 摘要卡 + 多行程纵向分段 + 历史折叠）。本节描述的创建态结构仍然有效，只是换了落点。
