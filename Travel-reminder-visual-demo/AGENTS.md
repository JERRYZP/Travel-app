# Travel Reminder Visual Demo
北京热门景点预约提醒工具的 H5 高保真视觉 demo，面向准备做微信小程序 MVP 的产品验证与视觉方向评估。

## 技术栈
- 语言/框架：原生 HTML、CSS、JavaScript
- 关键依赖：无外部构建依赖；页面使用静态 mock 数据与少量远程景点图片

## 目录结构
- `index.html`：demo 页面结构
- `styles.css`：视觉系统、响应式布局、组件样式
- `app.js`：mock 数据、交互状态、详情页和提醒设置逻辑
- `AGENTS.md`：项目约定，新增目录或文件前先同步这里

## 指令集
- 安装：无需安装
- 运行：直接用浏览器打开 `index.html`
- 本地服务：如需模拟移动端调试，可在项目目录执行 `python3 -m http.server 5173`

## 产品约定
- V1 demo 只有两个底部 Tab：`提醒` 与 `我的`
- 景点详情属于内页，不占用 Tab
- 不做“预约中心”和官方入口聚合页
- 真实网络能力、微信订阅消息、日历 `.ics` 导出先做视觉与状态模拟
- 涉及身份证、手机号的一键代填信息卡只使用假数据，不存储真实敏感信息

## 设计约定
- 视觉基调遵循新中式文化旅游：文雅、克制、温润、时效
- 主色使用故宫砖红 `#C0472A`，背景使用宣纸暖黄 `#F8F3EA`
- 卡片圆角不超过 8px，避免营销式大卡堆叠
- 页面优先服务“预约提醒决策”，不做泛旅游攻略首页

## 数据约定
- 预约规则尽量来自官方网页或政府门户
- 无法确认的规则必须在界面中标注为“待官方确认”或“以官方渠道为准”
- mock 数据需要保留 `sourceLabel` 与 `sourceUrl`

## 部署
静态站点，可部署到任意静态托管服务。当前阶段仅用于本地视觉验证。
